ПРОЕКТ ANDROID: «РОСГВАРДИЯ — СПРАВОЧНИК»
================================================

В проект добавлен HTML-прототип с краповым дизайном и логотипом кафедры из предоставленного PNG. APK ещё не собран: его можно собрать через GitHub Actions.

СБОРКА APK ЧЕРЕЗ GITHUB
1. Создайте отдельный репозиторий на GitHub.
2. Загрузите в репозиторий все файлы и папки этого проекта, включая скрытую папку .github.
3. Откройте вкладку Actions.
4. Выберите workflow «Build Rosgvardiya APK» и нажмите Run workflow (или дождитесь запуска после push).
5. После успешной сборки скачайте artifact «Rosgvardiya-reference-debug-apk» и распакуйте ZIP. Внутри будет app-debug.apk.
6. Передайте APK на Android и установите.

Проект не запрашивает разрешение INTERNET. Интерфейс, JSON и изображения хранятся внутри APK для автономной работы.

Важно: это первый Android-прототип. Перед распространением проверьте права на исходные тексты, базу и изображения, взятые из исходного APK. Логотип кафедры включён по запросу пользователя.
